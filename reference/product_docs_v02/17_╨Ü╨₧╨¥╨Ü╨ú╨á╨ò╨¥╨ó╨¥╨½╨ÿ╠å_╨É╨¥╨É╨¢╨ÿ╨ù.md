# 17. Конкурентный анализ Clinical Compass

> Дата снимка: 17.10.2026. Дополнение к `Clinical_Compass_team_pack/docs`. Метод: кабинетное исследование; 40 компаний из предыдущего отчёта и 7 дополнительных продуктовых аналогов, преимущественно по публичным материалам вендоров.

## Ключевые выводы

- **Функциональный аналог не равен конкуренту за одного и того же покупателя.** Measurement-based care, МИС, приложения напоминаний и research/PV закрывают разные части пути.
- **Скрининг и риск-алерты уже не уникальны:** Greenspace заявляет автоматические валидированные оценки, графики и risk flags; Limbic Access — conversational intake, risk triage и клинический отчёт.
- **AI clinical notes уже занятая категория:** Upheal и Eleos предлагают генерацию заметок после сессии; дифференцировать нужно целостным clinical workflow и правами доступа, а не просто LLM-summary.
- **Исследовательский рынок сформирован:** Medidata, REDCap, TriNetX, Signant и PV-системы обслуживают протоколы и большие корпоративные процессы. Новый продукт не должен выдавать exploratory patterns за подтверждённые ADR/эффект терапии.
- **Рекомендуемая стартовая позиция:** узкий русскоязычный модуль longitudinal monitoring / measurement-based care для врача, работающий вместе с МИС и patient-facing лёгким check-in.

## Ограничения источников и интерпретации

1. *Пользователи*, *пациентские профили*, *covered lives*, *клинические испытания*, *практики* и *скачивания* — разные метрики. Столбец «Масштаб» не следует использовать как сравнимый MAU.
2. Тарифы и пакеты из предыдущего отчёта относятся к снимку 17.10.2026; коммерческие условия могут различаться по стране и числу мест.
3. Отсутствие сведений о функции в публичных материалах **не означает**, что её нет в продукте. В матрице это `?`.
4. `◐` означает **смежную/частичную функцию** и не доказывает реализацию точного клинического требования. `●` следует использовать только для отдельно подтверждённого соответствия; в автоматическом сравнении принята консервативная маркировка `◐`.
5. Сведения из материалов вендоров — продуктовые заявления, не независимое клиническое доказательство.

## Что можно позаимствовать, но не копировать буквально

| Конкурент | Проверенный ориентир | Что лучше сделать в Clinical Compass |
|---|---|---|
| Greenspace | Scheduled validated PRO + clinician alert, shared graphs | Один timeline симптомов, приверженности, лечения; явные пробелы и действия по алерту |
| Mirah | Библиотека валидированных оценок, отчёты программы | Configurable шкалы с русскими версиями, правами и provenance |
| Osmind | Психиатрическая ЭМК, мобильное наблюдение, follow-up | Лёгкий workflow между визитами, без попытки переписать всё ЕМК |
| Upheal / Eleos | AI-конспектирование врачебных сессий | AI только как проверяемый черновик, без назначения терапии |
| Limbic Access | Диалоговый triage + clinical report | Пилот safety-архитектуры и эскалации без обещания валидированного автономного триажа |
| Medisafe / MyTherapy | Минимум усилий для логирования приёма | Разделять факт, позднюю ретроспективную оценку, пропуск и отсутствие данных |
| Practice Better | Портал, сообщения, визиты, задания | Patient self-service и запросы опросников до приёма, без перегрузки врачей |
| REDCap / Medidata | Словарь данных, контроль форм, историчность, согласия | Research только из утверждённых snapshot, с версионированием и политикой малых групп |
| TriNetX | Когорты и сравнительные анализы | Контроль смешения, quality/missingness, ограничения причинных выводов |
| Webiomed | СППВР, поиск рисков, интеграции, RWD | Ссылки на актуальные КР/ГРЛС, клиническое подтверждение, не black-box совет |

## Приоритетные конкуренты для дальнейшего исследования UX

1. **Greenspace / Mirah / Osmind** — physician overview, questionnaire delivery, insight review.
2. **Limbic / NeuroFlow** — триаж, критические сигналы, clinician responsibility.
3. **Upheal / Eleos** — клинические заметки, транскрипция и human review.
4. **MyTherapy / Medisafe / Bearable** — минимальное усилие пациента и ретроспективное логирование.
5. **REDCap / TriNetX / Medidata** — researcher side: cohort builder, data dictionary, export governance.
