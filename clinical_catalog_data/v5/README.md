## Семантика

**Методика терапии != авторский протокол**. Включены только самостоятельно написанные клинические описания; защищённые терапевтические мануалы не перепечатывались. Доказательность связи основана на описанных в карточке международных рекомендациях, часто с возрастными, фазовыми и контекстными ограничениями. Не все методы одинаково релевантны при каждом связанном диагнозе — данные должны пройти ревью медицинских специалистов.

**МНН != торговый препарат != зарегистрированное показание**. Все новые препараты представлены исключительно справочными карточками МНН без дозировок и без притворных инструкций/регистраций. Даже если связь названа guideline-supported, для России отмечены `ru_current_registration_verified=false` и `ru_indication_approved_verified=false`. Инструкции 8 брендовых препаратов скопированы по исходным байтам, не исправлялись; overlay хранит список кодов из этих инструкций, требующий сверки с действующим ГРЛС.

Нет автоматической постановки диагноза, назначения, расчёта дозы или проверки лекарственных взаимодействий. Без независимой экспертизы содержимое подходит только для синтетического прототипа / справочника с пометкой «требует медицинской проверки».

## Ограничения
- Более свежие/российские клинические рекомендации и юридический статус препаратов необходимо проверять перед медицинской эксплуатацией.
- Связи «медикамент — диагноз» не означают эффективность во всех подтипах и возрастах или статус регистрации в РФ.
- Если у диагноза нет препарата, это **не значит**, что лечение отсутствует: не найдена достаточная болезнь-специфическая связь в пределах этого выпуска.
- Особые ограничения для наркотических и психостимулирующих препаратов, лечения детей, репродуктивного риска (вальпроаты, топирамат), антипсихотиков при деменции и при применении препаратов вне инструкции.
