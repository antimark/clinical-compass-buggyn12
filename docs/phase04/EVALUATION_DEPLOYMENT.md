# Deployment scope and prerequisites
Verified target: existing macOS Apple Silicon M1/16GB-class environment, Conda cc-m1 Python3.11, existing Node/Chromium, installed local Ollama and qwen3:4b-instruct. No dependency/model installation is performed by the launcher. Apple `/usr/bin/sips` is used by existing profile-photo processing; other OS photo support is NOT_VERIFIED. CPU/GPU contention can extend model latency; one shared inference gate serializes Qwen and safety uses its own worker.

Use scripts/evaluation.sh from extracted source; it resolves the repository path, preserves existing PYTHONPATH and runs cc-m1. Alternative `CC_PYTHON=/absolute/existing/cc-m1/bin/python` avoids requiring Conda on PATH. `check` tests imports and loopback Ollama tags, not clinical accuracy. Failure2 means runtime/model unavailable; it never pulls weights. CLI help: `scripts/evaluation.sh --help`.

Private persistent --workspace must be outside the source folder, permissions0700; session.secret must be an ordinary0600file with >=32characters. A random stable secret is created only if absent, never printed or silently replaced. SQLite organizer-evaluation.sqlite is isolated; no global fixtures/reset. CC_DATABASE_URL is rejected by this launcher to prevent accidental shared/prodDB targeting. Existing workspace records survive normal serve/restart. Backups must include database and session/config under an operator policy; stop server/workers before copying SQLite or use an approved consistent backup procedure. Logical deletion does not erase existing snapshots/WAL/backups; database encryption is not newly established.

Profile: APP_ENV evaluation_sandbox, DEMO_MODE true, explicit acknowledgement, tenant evaluation_sandbox, unseeded ownDB. CI API/review/proposals/referrals/chat/safety functional defaults are on in this profile; explicit operator environment overrides still apply. Ordinary passwords/sessions and invitations/consent apply. CLI trusted-operator account provisioning creates doctor/clinic_admin/researcher only, never platform_admin/godmode, links or clinically verified credentials. Patient account registration stays the normal HTTP workflow. Real staff MFA/Keycloak/email/professional verification are NOT_ACCEPTED by local account provisioning.

Default bind127.0.0.1:8766; no clinical or remote public deployment accepted. Remote hosting/TLS/proxy/backup/key operations require a separate deployment/security decision. No package contains a default password, session secret, runtimeDB or real patient records. A provisional source ZIP can be built during QA with `python scripts/build_organizer.py --output /private/tmp/organizer-preview.zip --include-working`; final build must use reviewed committed source and omits this flag. The embedded manifest marks provisional archives and lists exact file hashes. Do not hand provisional archives to organizers as final.
