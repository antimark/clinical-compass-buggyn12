# Результаты проверок нового frontend

**Статус:** статическая и модельная проверка — выполнена; end-to-end browser/Flask — не выполнена.

| Проверка | Результат | Ограничения |
|---|---|---|
| Новый `dist/index.html`, CSP и загрузка только локальных CSS/JS | PASS (статический контроль) | Не проверено браузером |
| JavaScript syntax (`node --check`) | PASS | Не эквивалент runtime тесту в Safari |
| 95 путей из `routes.json` (отрисовка с отказами API) | PASS: 95/95 | API смоделированы в Node |
| 25 ключевых путей с фикстурами ответов | PASS: 25/25 | Не используются реальные cookies/CSRF/DB |
| Экранные роли, данные и DTO по backend | PARTIAL | Ручная сверка `backend/cc_api` и список в матрице; полной контрактной верификации нет |
| Реальный Flask server и исходный pytest | NOT RUN | В данной runtime среде `flask` не установлен |
| Chromium/Playwright: 360, 768, 1280px; screenshots | BLOCKED | Среда отвечает `net::ERR_BLOCKED_BY_ADMINISTRATOR` даже при перехвате запросов и file:// |
| Safari/macOS Liquid Glass | NOT RUN | Safari на этой платформе отсутствует |
| PostgreSQL, Keycloak/MFA, Qwen/Ollama, видеосвязь | NOT RUN | Сервисы не подняты; не объявлены работающими |
| Оригинальные frontend/browser тесты | NOT RUN | Их селекторы и старые DOM компоненты несовместимы с полной пересборкой; необходима переработка тестов |

**Риски:** непротестированные комбинации DTO и feature flags; формы подписанных клинических документов не интегрированы; часть страниц показывает read-only или unavailable; проверка ролевых прав должна включать реальные доступы. Все данные тестов являются синтетическими. Внос реальных медицинских данных в учебный контур запрещён.

## Дополнительная проверка Warm Frost (27.10.2026)

- `npm test`: 95/95 маршрутов, 25/25 сценариев, 17/17 проверок CSS-контрактов.
- Chromium: загрузка по локальному HTTP-адресу заблокирована политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`); полноценный E2E по-прежнему **не выполнен**.
- Разметка реальной главной страницы отрендерена в Chromium через `page.set_content` с актуальными CSS; вручную просмотрены статические снимки при 1280 и 390 px, а также проверена ширина страницы при 768 px. Горизонтального переполнения нет, капсульные кнопки имеют вычисленный радиус 999 px, фон светлой темы — rgb(255,255,255). Это **визуальная проверка статической разметки**, не имитация проверенного backend.
- Размытие фонового содержимого в Safari, поведение при реальном auth-меню и кликабельность в живом приложении требуют проверки на хосте пользователя.
